# 到期题卡片辅助信息可读性设计

## 目标

提高“打开原题”上方到期提示的可读性，同时保持现有题目卡片布局与信息层级。

## 设计

- 仅调整 `DueCard` 中“到期日期 · 先盲做，不看旧笔记”这一行。
- 字号从 `10px` 提升到 Tailwind 的 `text-xs`（`12px`）。
- 颜色改为 70% 前景色，提高深色背景下的对比度。
- 保留等宽字体、大写转换和现有字距，不修改文案或布局。

## 边界

- 不调整全站其他辅助文字。
- 不修改确定性排程、盲做投影字段、导入导出格式、数据库结构或迁移历史。

## 验证

- 增加一条页面源码回归测试，锁定该行的字号和颜色类。
- 运行完整 `npm test` 与 `npm run lint`。
